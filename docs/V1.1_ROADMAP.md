# v1.1 Roadmap — Ship the Product

**Prerequisite:** v1.0.0 tagged and defense complete.  
**Theme:** Operations, legal, and commercial — **no new AI models**.

---

## Priority: High

| Item | Description | Notes |
|------|-------------|-------|
| Landing page | Marketing + signup CTA | Positioning one-liner on hero |
| Privacy Policy | GDPR-style data handling | User data, Alpaca keys, logs |
| Terms of Service | Acceptable use | No investment advice |
| Financial disclaimer | Risk disclosure | Decision-support only |
| Email verification | Confirm accounts | SendGrid / Resend |
| Password reset | Forgot password flow | Token email |
| Production deployment | HTTPS + PostgreSQL | Supabase or managed Postgres |
| Backups | Automated DB backups | Daily minimum |

---

## Priority: Medium

| Item | Description |
|------|-------------|
| Stripe billing | Free / Pro tiers |
| Invite system | Closed beta gate |
| Monitoring | Sentry + uptime checks |
| Rate limiting | `/register`, `/signals` |
| CI/CD | GitHub Actions test + deploy |

---

## Explicitly deferred (v2.0)

- Live broker execution (real money)
- Multi-broker abstraction (IB, Binance, EGX brokers)
- Per-user signal universes
- Social / shared portfolios
