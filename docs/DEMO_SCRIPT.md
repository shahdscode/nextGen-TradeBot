# Defense & Demo Script (~15 minutes)

Use this flow for thesis presentation, examiner demo, or invite-only beta walkthrough.

**Positioning line (open and close with this):**

> NextGen TradeBot is an AI-powered quantitative research and paper-trading platform that provides complete decision provenance for every trading decision.

---

## 1. Register (2 min)

1. Open `/signup` → create `demo_user`
2. Login → lands on **`/app/home`** (Command Center)
3. Point out: multi-tenant SaaS, JWT auth, isolated sessions

**Say:** *"Each user gets their own paper account; AI signals are a shared research feed."*

---

## 2. Settings — Alpaca (1 min)

1. Go to **Settings** → paste Alpaca paper API keys (or skip if demo uses sim only)
2. Show `alpaca_configured: true` on Command Center refresh

**Say:** *"Broker credentials never leave the user's row — not a shared demo account."*

---

## 3. Command Center (3 min)

On **Home**, walk through:

- Portfolio Health score
- AI Confidence + Market Regime
- Today's performance
- Top BUY opportunities
- **Portfolio Insight** (AI advisor paragraph)
- Sector allocation donut
- Alerts

**Say:** *"This is the daily command center — users don't need four tabs to know what matters."*

---

## 4. Signals feed (2 min)

1. Open **Signals**
2. Pick one ticker → show action, confidence, SHAP reasons
3. Note US vs EGX and regime banner

**Say:** *"Signals are generated by the meta-learner when the artifact is present; otherwise regime-weighted fallback."*

---

## 5. Paper rebalance (3 min)

1. **Paper Trading** → Simulated session
2. Market: US → **Rebalance (execute)** with `mode=meta`
3. Show result: positions, regime badge, risk controls copy

Optional: Alpaca rebalance if keys configured.

**Say:** *"Same allocation engine for sim and Alpaca; risk engine applies stops and drawdown rules."*

---

## 6. Decision Provenance (3 min) — **highlight**

1. Scroll to **Trade Journal** → click **Explore** on a BUY
2. Walk the chain:
   - Meta probability
   - Model votes table (7 models)
   - Regime + technicals
   - Fundamentals (if available)
   - Risk: size, stop, target
   - **Final explanation**

**Say:** *"This is decision provenance — not a black box. Every trade has a documented origin."*

---

## 7. Research validation (2 min) — admin

Login as **admin** → **Backtest**

1. Show completed backtest metrics (Sharpe, drawdown, stress tests)
2. Mention walk-forward, OOF meta-learner training, same features as live

**Say:** *"Live signals and backtests share the same feature pipeline and validation protocol."*

---

## Backup talking points

| Question | Answer |
|----------|--------|
| Real money? | No — paper / decision-support only |
| Why 7 models? | Diversification; meta-learner learns optimal blend |
| Leakage? | Walk-forward folds, OOF-only meta training, 5-day target |
| vs TradingView? | We add ensemble AI + provenance, not charting |
| What's missing for public beta? | HTTPS, legal docs, Stripe, monitoring — not new models |

---

## Pre-demo checklist

- [ ] Backend running, `meta_learner.pkl` present
- [ ] At least one meta rebalance executed (populates trade journal)
- [ ] Two browser profiles for isolation demo (optional)
- [ ] `.env` has non-default JWT secret
